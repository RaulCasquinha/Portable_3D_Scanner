# Accel_Calib_stm32

Firmware of the accelerometer calibration: NUCLEO-WL55JC1, ADXL355 or ADXL345 on SPI1.
- Streams the readings and runs the capture of the positions.
- Sends every measurement to the PC app [`../remote-app`](../remote-app/README.md)
  over the ST-LINK virtual COM port (115200 8N1). The PC computes the fit.
- Optionally applies a flashed calibration (two defines in `app_calib_conf.h`) to its `$READ`
  values.


## Build and flash

1. Open STM32CubeIDE: **File → Import → Existing Projects into Workspace**, and select this
   folder.
2. Choose the sensor in `Application/App/Inc/app_calib_conf.h` (`APP_SENSOR` define).
3. **Project → Build**, then **Run** (or the `Accel_Calib_stm32 Debug` launch) to flash it
   through the ST-LINK.

The calibration is normally applied outside the board, with the parameters the PC app shows.
Optional, to correct on the board: copy the defines from its **Parameters** window into
`app_calib_conf.h`, then build and flash again.


## Folders

| Folder | Contents |
|---|---|
| [`Application/`](Application/README.md) | all the code that is not generated: the application and the libraries |
| [`docs/`](docs/README.md) | the architecture diagram |
| `Core/` | generated by STM32CubeMX; user code only between the `USER CODE` markers (`main.c` calls `APP_Init()` and `APP_Run()`) |
| `Drivers/` | ST HAL, BSP and CMSIS, generated; not edited |
| `Debug/` | build output, not committed |
