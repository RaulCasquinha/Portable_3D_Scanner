# ExtraModels

Downloaded component reference models used for mechanical context inside FreeCAD. **These are not printed** — they exist so the enclosure design can be checked for fit against real component dimensions.

## Contents

| Directory / File | Component |
|-----------------|-----------|
| `esp32-s3-wroom-1-1.snapshot.2/` | ESP32-S3-WROOM-1 module (STEP + SolidWorks) |
| `female-header-pins-2.snapshot.2/` | Female pin headers 2–10 pins (STEP) |
| `lsm6ds3-imu-1.snapshot.1/` | LSM6DS3 IMU breakout (STEP) |
| `universal_board_40x60mm-1.snapshot.2/` | 40×60 mm universal PCB (STEP/IGS) |
| `vl53l0x-4.snapshot.11/` | VL53L0X ToF sensor module (STEP + Fusion 360) |

Sources: GrabCAD / Onshape public libraries.
